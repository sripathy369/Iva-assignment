 🖼️ IMAGE PROCESSING

An interactive web-based Image Processing Laboratory developed using Python and Streamlit.

This application provides a visual and interactive way to understand image processing concepts such as Spatial Domain Processing, Image Filtering, Gradient Operators, Kernel Convolution, Edge Detection, and live pixel-level calculations.

🌐 Live Demo

👉 https://share.google/SKhvtaPlOALnECv3p

 ✨ Features

- Interactive 3 × 3 kernel visualization
- Spatial Domain image processing
- Blur / Average filtering
- Gaussian-like Blur
- Sharpening
- Emboss effect
- Outline detection
- Sobel X and Sobel Y operators
- Prewitt X and Prewitt Y operators
- Laplacian operator
- Roberts X and Roberts Y operators
- Custom 3 × 3 kernel
- Interactive pixel selection
- Live kernel calculation
- Pixel × Kernel visualization
- Input and output image comparison

 📚 Concepts Demonstrated

- Spatial Domain Processing
- Image Filtering
- Convolution
- Gradient Operators
- Edge Detection
- Kernel Operations

 🛠️ Technologies Used

- Python
- Streamlit
- NumPy
- Plotly
- SciPy
- Pillow
- streamlit-plotly-events

🎯 Purpose

This project is designed as an interactive educational laboratory for learning image processing concepts through visual demonstrations and real-time calculations.
